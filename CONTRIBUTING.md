# Contributing to Awesome AI Resume Resources

Thank you for helping keep this list useful. **Quality over quantity** — we reject most PRs that look like SEO spam.

## What we accept

- Open-source prompts, datasets, or frameworks with **standalone educational value**
- Tools that improve resume **credibility** (clarity, honesty, ATS parseability)
- Articles with worked examples and recruiter-trusted language
- Communities with active moderation

## What we reject

- AI detector bypass / "humanize to fool Turnitin" tools
- Keyword stuffing guides or hidden-text tricks
- Affiliate-heavy listicles with no original examples
- Repositories that are empty README SEO bait
- Anything encouraging invented metrics or fake experience

## PR checklist

- [ ] Link works and is relevant to AI resumes / ATS / recruiting
- [ ] One sentence explains *why* it's useful (not marketing copy)
- [ ] Placed in the correct section alphabetically
- [ ] No duplicate of an existing entry
- [ ] You have used the resource yourself (or cite a credible source)

## Suggest via issue

Use the [Suggest a resource](.github/ISSUE_TEMPLATE/suggest-resource.md) template if unsure before opening a PR.

## Code of conduct

Be direct, be honest, no harassment. Maintainers may close issues without debate on clear spam.
